# Random Name Generator

A mobile-friendly GitHub Pages website generated from the supplied class spreadsheet.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `random-name-generator`.
2. Upload all files from this folder to the top level of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the **main** branch and **/(root)** folder, then click **Save**.
6. GitHub will show the live website address on the Pages settings screen.

## Edit class lists

Open `names.js`. Each class name is followed by its list of student names. Keep names inside quotation marks and separated by commas.
